Under the hood

Every button is a C++ cin / cout conversation

This page has no grade logic in JavaScript. Each click builds a text command, hands it to a C++ function called run(), and C++ reads it with cin and answers with cout. Open the to watch it happen.

  1. 1ClickJavaScript builds a command like grade 1001 "Quiz 3" quiz 88
  2. 2run()The text goes into WebAssembly. cin is pointed at it, and cout at an empty string.
  3. 3CommandShellReads the command word with cin >> and calls the right method
  4. 4GradeBook + StudentThe objects do the math: weighted averages, status, curve…
  5. 5coutC++ writes a reply (and a json snapshot of the class)
  6. 6UIJavaScript draws what C++ said: toasts, tables, charts
